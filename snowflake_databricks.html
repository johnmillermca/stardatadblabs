1. Architecture Overview

All three engines read the same Parquet files on S3. Spark is the primary write engine. Snowflake reads via an IAM-authenticated External Volume (no Polaris needed). Databricks reads via PyIceberg's S3 FileSystem catalog, then materialises data into Delta for SQL access.

Part A — Create the Iceberg Table with Spark

Skip to Part B if the table already exists on S3.

1
Fetch credentials from secrets manager

Retrieve Polaris service-account credentials and S3 keys. Example using OpenBao / Vault KV v2:

import urllib.request, json, os

VAULT_ADDR  = "http://<VAULT-HOST>:<PORT>"
VAULT_TOKEN = "REDACTED — paste root token here"

def _vault(path):
    req = urllib.request.Request(
        f"{VAULT_ADDR}/v1/{path}",
        headers={"X-Vault-Token": VAULT_TOKEN}
    )
    return json.loads(urllib.request.urlopen(req, timeout=10).read())["data"]["data"]

pol = _vault("secret/data/platform/polaris")   # keys: spark_svc_id, spark_svc_secret
s3  = _vault("secret/data/platform/s3")        # keys: access_key, secret_key, endpoint, region
print("✅ Credentials loaded")

Start Spark session pointing at the Polaris REST catalog 
from pyspark.sql import SparkSession
import os, socket

DRIVER_IP   = os.environ.get("SPARK_LOCAL_IP", socket.gethostbyname(socket.gethostname()))
POLARIS_URI = "http://<POLARIS-HOST>/api/catalog"
CATALOG     = "polaris"

spark = (
    SparkSession.builder
    .master("spark://<SPARK-MASTER>:<PORT>")
    .appName("iceberg-table-setup")
    .config("spark.cores.max",          "1")
    .config("spark.executor.instances", "1")
    .config("spark.executor.cores",     "1")
    .config("spark.executor.memory",    "2g")
    .config("spark.driver.host",        DRIVER_IP)
    .config("spark.driver.bindAddress", DRIVER_IP)
    .config("spark.sql.extensions",
            "org.apache.iceberg.spark.extensions.IcebergSparkSessionExtensions")
    # ── Iceberg REST catalog (Polaris) ────────────────────────────────────
    .config(f"spark.sql.catalog.{CATALOG}",
            "org.apache.iceberg.spark.SparkCatalog")
    .config(f"spark.sql.catalog.{CATALOG}.type",             "rest")
    .config(f"spark.sql.catalog.{CATALOG}.uri",              POLARIS_URI)
    .config(f"spark.sql.catalog.{CATALOG}.oauth2-server-uri",
            f"{POLARIS_URI}/v1/oauth/tokens")
    .config(f"spark.sql.catalog.{CATALOG}.credential",
            f"{pol['spark_svc_id']}:{pol['spark_svc_secret']}")   # REDACTED at runtime
    .config(f"spark.sql.catalog.{CATALOG}.scope",            "PRINCIPAL_ROLE:ALL")
    .config(f"spark.sql.catalog.{CATALOG}.warehouse",        "<ICEBERG-CATALOG-NAME>")
    .config(f"spark.sql.catalog.{CATALOG}.rest.auth.type",   "oauth2")
    .config(f"spark.sql.catalog.{CATALOG}.s3.access-key-id",     s3["access_key"])
    .config(f"spark.sql.catalog.{CATALOG}.s3.secret-access-key", s3["secret_key"])
    .config(f"spark.sql.catalog.{CATALOG}.s3.endpoint",          s3["endpoint"])
    .config(f"spark.sql.catalog.{CATALOG}.s3.path-style-access", "true")
    .config(f"spark.sql.catalog.{CATALOG}.client.region",        s3.get("region", "us-east-1"))
    # ── S3A Hadoop filesystem layer ───────────────────────────────────────
    .config("spark.hadoop.fs.s3a.impl",
            "org.apache.hadoop.fs.s3a.S3AFileSystem")
    .config("spark.hadoop.fs.s3a.access.key",        s3["access_key"])
    .config("spark.hadoop.fs.s3a.secret.key",        s3["secret_key"])
    .config("spark.hadoop.fs.s3a.endpoint",          s3["endpoint"])
    .config("spark.hadoop.fs.s3a.path.style.access", "true")
    .getOrCreate()
)
spark.sparkContext.setLogLevel("WARN")
print("✅ Spark", spark.version, "connected —", DRIVER_IP)

NAMESPACE = "<namespace>"     # e.g. "lakehouse"
TABLE     = "<table>"         # e.g. "events"
BUCKET    = "<YOUR-BUCKET>"

spark.sql(f"CREATE NAMESPACE IF NOT EXISTS {CATALOG}.{NAMESPACE}")

        id         BIGINT        NOT NULL,
        source     STRING,
        event_type STRING,
        user_id    BIGINT,
        amount     DOUBLE,
        ts         TIMESTAMP     NOT NULL,
        payload    STRING

    TBLPROPERTIES (
        'write.format.default'            = 'parquet',
        'write.parquet.compression-codec' = 'snappy',
        'write.target-file-size-bytes'    = '2684354'
    )

""")

Part B — Connect to Snowflake

Snowflake reads Iceberg metadata directly from S3 via an IAM role (CATALOG = 'OBJECT_STORE'). Polaris connectivity is not required. All SQL runs in the Snowflake Worksheet as ACCOUNTADMIN.

Never recreate the External Volume once it exists. Each CREATE OR REPLACE EXTERNAL VOLUME generates a new ExternalId which requires updating the AWS IAM trust policy again.
1

Create an IAM role. After creating the External Volume in Step 2, Snowflake generates the exact trust values you must paste into this role's trust policy.

5
Register the Iceberg table in Snowflake

BASE_LOCATION is relative to the External Volume's STORAGE_BASE_URL: s3://<YOUR-BUCKET>/warehouse/ + <namespace>/<table>/

USE ROLE ACCOUNTADMIN;

CREATE DATABASE IF NOT EXISTS <DATABASE_NAME>;
USE DATABASE <DATABASE_NAME>;
CREATE SCHEMA IF NOT EXISTS <SCHEMA_NAME>;
USE SCHEMA <SCHEMA_NAME>;

CREATE OR REPLACE ICEBERG TABLE <table_name>
    CATALOG           = 'iceberg_object_store'
    EXTERNAL_VOLUME   = 'iceberg_s3_vol'
    BASE_LOCATION     = '<namespace>/<table>/'
    METADATA_FILE_PATH = 'metadata/<filename-from-step-4>.metadata.json';

-- Verify: row count should match Spark output
SELECT COUNT(*) FROM <table_name>;
SELECT * FROM <table_name> LIMIT 10;
6
Schedule automatic hourly metadata refresh

Each Spark write advances the S3 metadata pointer. This Snowflake Task re-reads it every hour so Snowflake always sees fresh data.

USE ROLE ACCOUNTADMIN;
USE DATABASE <DATABASE_NAME>;
USE SCHEMA <SCHEMA_NAME>;

CREATE OR REPLACE TASK refresh_<table_name>
    WAREHOUSE = COMPUTE_WH
    SCHEDULE  = 'USING CRON 0 * * * * UTC'   -- every hour at :00
    COMMENT   = 'Hourly Iceberg metadata refresh via S3 OBJECT_STORE'
AS
    ALTER ICEBERG TABLE <DATABASE_NAME>.<SCHEMA_NAME>.<table_name> REFRESH;

-- Tasks are created SUSPENDED — must explicitly resume:
ALTER TASK refresh_<table_name> RESUME;

-- Confirm state = started
SHOW TASKS LIKE 'refresh_<table_name>';

-- Check execution history (last 24 h)
SELECT name, state, scheduled_time, completed_time, error_code, error_message
FROM TABLE(INFORMATION_SCHEMA.TASK_HISTORY(
    SCHEDULED_TIME_RANGE_START => DATEADD('hour', -24, CURRENT_TIMESTAMP),
    TASK_NAME => 'refresh_<table_name>'
))
ORDER BY scheduled_time DESC LIMIT 10;

-- Manual one-shot refresh (no task needed):
ALTER ICEBERG TABLE <DATABASE_NAME>.<SCHEMA_NAME>.<table_name> REFRESH;

Cell 5 — Auto-discover and register all Iceberg tables from S3

Walks s3://<YOUR-BUCKET>/iceberg/warehouse/<db>/<table>/metadata/ and registers the latest snapshot for every table found.

import s3fs

fs = s3fs.S3FileSystem(
    key=S3_ACCESS_KEY, secret=S3_SECRET_KEY,
    endpoint_url=S3_ENDPOINT,
    client_kwargs={"region_name": S3_REGION},
)

warehouse_bare = WAREHOUSE_ROOT.replace("s3://", "", 1).rstrip("/")
registered, skipped, errors = [], [], []

for db_path in fs.ls(warehouse_bare, detail=False):
    db_name = db_path.rstrip("/").split("/")[-1]
    try: catalog.create_namespace((db_name,))
    except: pass

    for tbl_path in fs.ls(db_path, detail=False):
        tbl_name    = tbl_path.rstrip("/").split("/")[-1]
        meta_prefix = tbl_path.rstrip("/") + "/metadata"
        identifier  = (db_name, tbl_name)
        try:
            meta_files = sorted(
                [f for f in fs.ls(meta_prefix, detail=True)
                 if f["name"].endswith(".metadata.json")],
                key=lambda f: f.get("LastModified", 0), reverse=True
            )
            if not meta_files:
                skipped.append(f"{db_name}.{tbl_name}")
                continue
            latest = "s3://" + meta_files[0]["name"]
            try: catalog.drop_table(identifier)
            except: pass
            catalog.register_table(identifier, latest)
            registered.append(f"{db_name}.{tbl_name}")
        except Exception as exc:
            errors.append((f"{db_name}.{tbl_name}", str(exc)))

print(f"✅ Registered {len(registered)} table(s):")
for t in registered: print(f"   {t}")
if skipped:  print(f"\n⏭  Skipped (no metadata): {skipped}")
if errors:   print(f"\n⚠️  Errors: {errors}")

Part D — Databricks Serverless / Unity Catalog (Production Path)

On Databricks Serverless compute, spark.conf.set("fs.s3a.*") is on a hard blocklist and dbutils.fs.ls("s3://...") returns 403. This path bypasses both restrictions: all S3 I/O goes through boto3 (credentials from os.environ), and Spark only writes/reads Delta — never S3 directly.

This path produces Unity Catalog Delta tables (snap_<table>_latest) with UC views (vw_<table>_latest) on top — queryable from the SQL console or BI tools connected to UC.

Cell 3 — Auto-discover all Iceberg tables via boto3 (serverless-safe) 
import boto3

s3_client = boto3.client(
    "s3",
    aws_access_key_id     = AK,
    aws_secret_access_key = SK,
    region_name           = S3_REGION,
    endpoint_url          = S3_ENDPOINT,
)

def s3_list_dirs(bucket, prefix):
    prefix = prefix.rstrip("/") + "/"
    paginator = s3_client.get_paginator("list_objects_v2")
    dirs = []
    for page in paginator.paginate(Bucket=bucket, Prefix=prefix, Delimiter="/"):
        for cp in page.get("CommonPrefixes", []):
            dirs.append(cp["Prefix"])
    return dirs

def s3_list_files(bucket, prefix, suffix=""):
    prefix = prefix.rstrip("/") + "/"
    paginator = s3_client.get_paginator("list_objects_v2")
    files = []
    for page in paginator.paginate(Bucket=bucket, Prefix=prefix):
        for obj in page.get("Contents", []):
            if not suffix or obj["Key"].endswith(suffix):
                files.append(obj)
    return files

TABLE_CONFIGS = {}

for db_prefix in s3_list_dirs(S3_BUCKET, S3_PREFIX):
    db_name = db_prefix.rstrip("/").split("/")[-1]
    for tbl_prefix in s3_list_dirs(S3_BUCKET, db_prefix):
        tbl_name = tbl_prefix.rstrip("/").split("/")[-1]
        key      = f"{db_name}.{tbl_name}"
        if key in SKIP_TABLES:
            continue
        meta_objs = s3_list_files(S3_BUCKET, tbl_prefix.rstrip("/") + "/metadata", ".metadata.json")
        if not meta_objs:
            continue
        safe_db  = db_name.replace(".", "_").lstrip("_")
        safe_tbl = tbl_name.replace(".", "_").lstrip("_")

Cell 4 — Define resolve_live_files() — manifest walk (pure Python, no Spark S3 I/O)

Walks metadata JSON → manifest-list (Avro) → data manifests (Avro) to collect exactly the live Parquet file keys for the current snapshot. Automatically detects and skips merge-on-read tables.

import json, datetime, io, fastavro

def _norm(p):  return p.replace("s3a://", "s3://") if p else p

def _s3_json(key):
    return json.loads(s3_client.get_object(Bucket=S3_BUCKET, Key=key)["Body"].read())

def _s3_avro(key):
    buf = io.BytesIO(s3_client.get_object(Bucket=S3_BUCKET, Key=key)["Body"].read())
    return list(fastavro.reader(buf))

def _s3_key(s3_path):
    p = _norm(s3_path)
    prefix = f"s3://{S3_BUCKET}/"
    if p.startswith(prefix): return p[len(prefix):]
    raise ValueError(f"Path not in bucket {S3_BUCKET}: {s3_path}")

def resolve_live_files(table_name, tbl_prefix):
    meta_objs = s3_list_files(S3_BUCKET, tbl_prefix + "/metadata", ".metadata.json")
    if not meta_objs: raise RuntimeError(f"[{table_name}] No metadata.json found")
    meta_objs.sort(key=lambda o: o["LastModified"], reverse=True)
    top       = meta_objs[0]
    meta_name = top["Key"].split("/")[-1]
    meta_ts   = top["LastModified"].strftime("%Y-%m-%d %H:%M:%S UTC")
    meta      = _s3_json(top["Key"])

    snap_id = meta.get("current-snapshot-id")
    if snap_id is None:
        print(f"  [{table_name}] No snapshot — table empty")
        return {"live_files":[], "meta_name":meta_name, "meta_ts":meta_ts, "mor_skip":False}

    cur = next((s for s in meta.get("snapshots",[]) if s.get("snapshot-id")==snap_id), None)
    if cur is None: raise RuntimeError(f"[{table_name}] Snapshot {snap_id} not in snapshots[]")

    total = int(cur.get("summary",{}).get("total-records",-1))
    if total == 0:
        print(f"  [{table_name}] total-records=0 — table empty after DELETE")
        return {"live_files":[], "meta_name":meta_name, "meta_ts":meta_ts, "mor_skip":False}

    ml_rows = _s3_avro(_s3_key(_norm(cur.get("manifest-list",""))))

    # Detect merge-on-read (position-delete manifests)
    if any(r.get("content",0)==1 for r in ml_rows):
        print(f"  [{table_name}] ⚠️  MERGE-ON-READ detected — SKIPPED")
        return {"live_files":[], "meta_name":meta_name, "meta_ts":meta_ts, "mor_skip":True}

    data_manifest_paths = [_norm(r["manifest_path"]) for r in ml_rows if r.get("content",0)==0]
    all_rows = []
    for mp in data_manifest_paths:
        all_rows.extend(_s3_avro(_s3_key(mp)))

    file_status = {}
    for row in all_rows:
        df = row.get("data_file") or row.get("r2_deleted_data_file") or {}
        if isinstance(df, dict) and df.get("content",0) != 0: continue
        fp = _norm(df.get("file_path","") if isinstance(df,dict) else "")
        if not fp: continue
        st = row.get("status", 1)
        ex = file_status.get(fp)
        if ex is None: file_status[fp] = st
        elif st == 0:  file_status[fp] = 0
        elif ex != 0 and st == 2: file_status[fp] = 2

    live = [p for p,s in file_status.items() if s in (1,2)]
    dead = sum(1 for s in file_status.values() if s==0)
    print(f"  [{table_name}]  snapshot={snap_id}  meta={meta_name}  ({meta_ts})")
    print(f"    live_files={len(live)}  dead_files={dead}  manifests={len(data_manifest_paths)}")
    return {"live_files":live, "meta_name":meta_name, "meta_ts":meta_ts, "mor_skip":False}

print("✅ resolve_live_files() defined")

Cell 6 — Write Unity Catalog Delta tables + create UC views

Downloads live Parquet files via boto3 → PyArrow in-memory → Spark DataFrame → Delta table. Spark never touches S3 directly.

import pyarrow.parquet as pq, pyarrow as pa, io as _io

def read_parquet_from_s3(keys):
    tables = []
    for key in keys:
        resp = s3_client.get_object(Bucket=S3_BUCKET, Key=key)
        buf  = _io.BytesIO(resp["Body"].read())
        tables.append(pq.read_table(buf))
    if not tables: return pa.table({})
    unified = pa.unify_schemas([t.schema for t in tables])
    return pa.concat_tables([t.cast(unified) for t in tables])

Troubleshooting
Snowflake returns 0 rows after a Spark write
  1. Run a manual refresh: ALTER ICEBERG TABLE <DB>.<SCHEMA>.<table> REFRESH;
  2. Check task state: SHOW TASKS LIKE 'refresh_<table>'; — must be started
  3. If suspended: ALTER TASK refresh_<table> RESUME;
Snowflake EXTERNAL VOLUME — STS AssumeRole denied
  1. DESCRIBE EXTERNAL VOLUME iceberg_s3_vol; — copy STORAGE_AWS_IAM_USER_ARN and STORAGE_AWS_EXTERNAL_ID.
  2. Go to AWS IAM → your Snowflake role → Trust relationships.
  3. Verify the principal ARN and ExternalId match exactly. Update if they differ.
  4. Never recreate the External Volume — each CREATE OR REPLACE generates a new ExternalId.
PyIceberg PermissionError listing S3 / 403 on Databricks
  1. Ensure widget values in Cell 2 are filled in before running Cell 3+.
  2. Confirm WAREHOUSE_ROOT ends with a trailing slash and points to the right bucket.
  3. Verify the IAM user/key has s3:ListBucket and s3:GetObject on the bucket.
  4. Re-run Cell 1 (%pip install) if you attached to a new cluster — packages must be reinstalled per session.
botocore / boto3 version conflict on Databricks Free Edition

Symptom: ImportError or AttributeError referencing botocore after %pip install pyiceberg.

%pip install "botocore>=1.40.45,<1.41.0" "boto3>=1.40.45,<1.41.0" --quiet
Databricks Serverless: spark.conf.set("fs.s3a.*") fails with CONFIG_NOT_AVAILABLE

This is a hard blocklist on serverless compute. Use Part D (boto3 path) — never set fs.s3a.* keys on serverless. Spark should only read/write Delta; boto3 handles all S3 I/O.

PyIceberg: merge-on-read table reads return incorrect/missing rows

Tables written by Presto/Trino use position-delete files (merge-on-read). PyIceberg's scan() may not apply delete files correctly without the full Iceberg engine JAR. In Part D, these tables are auto-detected and skipped. For MoR tables, use Spark or Trino to read instead.

Snowflake metadata drift — refresh fails after many Spark snapshots

The registered metadata snapshot pointer lags too far behind. Follow the re-registration steps in Part E.
